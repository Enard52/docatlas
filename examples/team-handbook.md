# Example team handbook

This is fictional sample content for a local DocAtlas walkthrough.

## Release notes

Release notes are retained for 90 days. Each release note records the version,
observable changes and rollback instructions. The release owner verifies the notes
before publishing them.

## Access reviews

Workspace access is reviewed every month. An administrator removes access that is
no longer required. Credentials and private customer documents must not be included
in public bug reports.
